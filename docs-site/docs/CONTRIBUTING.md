# 🤝 Guide de contribution

Bienvenue dans ce projet de test !  
Même si c’est un bac à sable perso, voici un exemple de guide pour s'entraîner à rédiger ce genre de fichier.

## Étapes pour contribuer

1. Fork le projet
2. Crée une branche : `feature/nom-feature`
3. Fais tes modifications
4. Push ta branche
5. Ouvre une Pull Request (PR)

## Bonnes pratiques

- Un commit = une idée claire
- Utilise des messages de commit explicites
- Garde un changelog à jour
